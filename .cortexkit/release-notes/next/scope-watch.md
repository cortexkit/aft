AFT now follows scope endings through the daemon's `scope.watch` feed instead of periodically re-describing healthy watched scopes. Each ending is confirmed with `scope.describe` before stopping shell tasks, deleting saved grants, or settling held calls. Older daemons and interrupted watches retain polling until watches can be re-armed; reconnects and live epoch changes alone never revoke a scope. Health includes watch coverage and the number of scopes still using polling.

# Background notice rendering parity

`inputs.json` is shared input for AFT's Rust notice renderer and the original
OpenCode plugin renderers in `packages/opencode-plugin/src/bg-notifications.ts`:
`formatSystemReminder`, `formatLongRunningReminder`, and
`formatPatternMatchReminder`. `vectors.json` was generated by those TypeScript
functions, not by the Rust code under test.

The Rust test `runner_notice_text_matches_original_typescript_renderers` compares
every byte, including the `<system-reminder>` wrapper. Fixtures cover subsecond
rounding, minute rollover, negative duration suppression, JavaScript number
printing beyond the exact-integer range and at exponent notation, ANSI stripping,
truncation guidance, incomplete capture, descendants, changed-file text, long
commands, watch batches, and lost-notification/secret-scan notes.

Notices to runner sessions retain this wording. Plugin sessions retain their
existing frame-based renderers and acknowledgements.

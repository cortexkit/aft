# Vendored Cingulate requester samples

`cingulate-secret-use-approval-v1/` is an untouched copy of Cingulate's
`test-vectors/secret-use-approval-v1/` at source commit `56fa35f2`.
Its twelve files are pinned by the accompanying `SHA256SUMS`. The keys and
signatures are public deterministic test material, not live credentials.

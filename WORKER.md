# Worker reference: byte-drift artifacts

The build and test gate instructions are in [`.cortexkit/WORKER.md`](.cortexkit/WORKER.md).
Run Cargo jobs on the build server as described there, from this worktree.

## Byte-drift artifacts

| Artifact | Regeneration command (repository root) | Drift check |
| --- | --- | --- |
| `crates/aft/src/subc_tool_schemas.json` | `bun run --cwd packages/opencode-plugin build:tool-schemas` | Generated bytes must match the committed file. |
| `crates/aft/tests/fixtures/rich_ui/aft-rich-ui-manifest-v1.json` | `cargo test -p agent-file-tools --lib -- regenerate_rich_ui_samples --ignored --nocapture` | `cargo test -p agent-file-tools --lib -- rich_ui_samples` |

The rich-UI generator calls the real session-read and observation-only Bash
handlers through ToolProviderV1 `tool.call` requests by the read-only UI carrier
principal, `reserved:occipital`, with an injected test manifest. It
does not publish a production manifest or run shell commands. Review generated
diffs as changes to the rich-UI reply contract, not as incidental snapshot churn.
The fixture README documents normalization and the capture boundary.

# v0.63.5

AFT 0.63.5 fixes two problems introduced in 0.63.4. It has no other changes.

## Fixed

- AFT starts again inside a Linux sandbox that does not let it read the disk root, such as nono with Landlock. 0.63.4 stopped at startup there ([#1245](https://github.com/cortexkit/aft/issues/1245)).
- `aft_inspect` on two or more files outside the project no longer fails with "refused again after it was approved" after the first approval in OpenCode 2 daemon mode ([#1258](https://github.com/cortexkit/aft/issues/1258); thanks @iceteaSA).

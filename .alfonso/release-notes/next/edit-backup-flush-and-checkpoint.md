- Edits, writes and patches on macOS return sooner, most of all while the disk is busy. Their undo snapshot now does one fewer device-cache flush. Its undo-history write no longer waits for an aft.db WAL checkpoint, and waits at most 50 ms for the daemon's shared database connection and other aft.db writers. Past that, the next edit of the same file catches the history up. Undo reads the snapshot files on disk, so it is unaffected.

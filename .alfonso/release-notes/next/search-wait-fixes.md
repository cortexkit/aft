- `aft_search` no longer makes concurrent searches of one project embed their queries one at a time: a query whose embedding is already cached answers at once instead of waiting behind another search's embedding call, and two searches with the same query text share one embedding call. Searches for a file name such as `subc_format.rs` read the index's path list instead of walking the project, while AFT's file watcher keeps that list current. The daemon's slow-call log line for `aft_search` now names what the search waited on (`waits=` and `search_cpu=`).

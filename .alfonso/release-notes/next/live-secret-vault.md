Shell `{{ck-secret:<label>}}` placeholders now use the live vault over AFT's authenticated daemon route. Each HTTPS request is checked against its real host and path; released keys are inserted only at the vault's designated location and are never reused to authorize another request. Requests needing phone approval share the same pending vault request's card, with one 10-minute deadline across all labels in each HTTP request. Cancelling the last waiter withdraws its card. URL fetches also ask per request and redirect, and never retry a credential-bearing send. Standalone use remains fail-closed, and keys stay out of command output, task logs and status replies.

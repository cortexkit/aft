Shell `{{ck-secret:<label>}}` placeholders now use the live vault over AFT's authenticated daemon route. Each HTTPS request is checked against its real host and path; released keys are inserted only at the vault's designated location and are never reused to authorize another request. Requests needing phone approval wait up to 10 minutes, sharing one pending card per scope and label. URL fetches also ask per request and redirect. Standalone use remains fail-closed, and keys stay out of command output, task logs and status replies.

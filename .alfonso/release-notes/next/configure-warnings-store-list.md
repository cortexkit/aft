- Configure's missing-tool and missing-language-server warnings no longer walk the whole project on each configure once the root's index-store checkout has published. The pass takes the source file list from the checkout, as the background TODO refresh already does, and needs only the files' paths. It still walks when the store's list can't stand in for a walk: no checkout is bound or published yet (usually on a new root's first configure), a rescan against the disk is pending, the folder is a folder of repositories or one the index store never indexes, or confinement or a Jujutsu-only repository applies different ignore rules. Each such walk logs `configure warning files walked: reason=<reason> files=<n> ms=<ms>`.

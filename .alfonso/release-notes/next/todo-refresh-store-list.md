- The status bar's background TODO refresh no longer walks the whole project to list its files. It takes the list from the root's index-store checkout, the same list `aft_inspect` already used, and the disk is no longer stat'ed once per file. It still walks the folder in four cases: no checkout is bound or published yet, a rescan of the checkout against the disk is pending, the folder is a folder of repositories or one the index store never indexes, or a request fenced to part of the root (confinement) or a Jujutsu-only repository applies different ignore rules. Each such walk logs `inspect scope files walked: reason=<reason> files=<n> ms=<ms>`. In a replay of 430 edits on a copy of AFT's repository (6,003 source files, debug build), the 43 listings walked 0 times instead of 43. They used 45 ms of CPU each instead of 130 ms, and every list matched the walk's.

- `glob`, `grep` and `outline` on a large directory outside the project (such as `~/.cargo/registry/src`) now return the files found so far, marked as a partial walk, instead of a `read_blocked` error that told agents to change macOS Privacy & Security settings. `read_blocked` is now reserved for one filesystem call that stops responding; it names that path, and a walk that stalls keeps what it had already found. A walk the request stops waiting for now exits and frees its helper slot.

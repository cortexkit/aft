- A slow `aft_outline` or `aft_zoom` of a web page now says in the daemon log where the time went: the slow-call line carries a `url_fetch=` field with the cache hit count and the milliseconds spent on the address check, connecting, waiting for the server's first byte, reading the body and converting HTML, plus body bytes, redirects, retries and any timeout phase. The URL itself is never logged.

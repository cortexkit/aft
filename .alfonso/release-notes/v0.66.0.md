# v0.66.0

AFT 0.66 drastically reduces the memory the first index build of very large projects needs, resumes an interrupted build instead of starting over, and adds downloadable grammars, starting with Luau. It also adds opt-in per-project shell environments from mise, direnv or your own command, returns foreground shell commands as soon as they exit, and fixes the problems reported since 0.65.

## Upgrading

- This version reindexes: each project's call graph is rebuilt once, automatically, the first time it is used after the upgrade, which takes extra CPU for a while. Text and meaning search indexes are kept. Builds keep temporary files on disk while they run, so leave some free space.
- On macOS, AFT's own file flushes use plain `fsync`; set `durability.macos_full_sync: true` in your user config to restore full drive flushes ([docs](https://github.com/cortexkit/aft/blob/main/docs/config.md)).
- Building from source: downloadable grammars, and so Luau, need `--features wasm-grammars` and CMake 3.18 or newer. Released binaries already include them.

## Downloadable grammars, starting with Luau

AFT can now add a language without a new AFT build: the language's grammar is downloaded the first time a project uses it, instead of being compiled into AFT. Luau is the first such language, and the 33 built-in languages are unchanged.

- Luau projects get outlines, navigation, call graphs, search and TODO inspection (#1063, thanks @Sandvich1337).
- Each grammar is pinned by hash and checked before it loads. It runs in WebAssembly on an interpreter, never as native code, so a faulty grammar can't run code on your machine, and a parse that runs too long is stopped.
- The first Luau file needs network access to fetch the grammar; after that it's stored locally. When the grammar can't be fetched, Luau files are reported as unavailable instead of silently skipped.
- Released binaries include this on every platform. Source builds need `--features wasm-grammars` and CMake 3.18 or newer ([details](https://github.com/cortexkit/aft/blob/main/docs/grammars.md)).

## New

- Opt-in per-project shell environments: set `shell.env_provider` to `mise`, `direnv` or a custom command in your user config (#1461, thanks @gaojunran).
- An interrupted first call-graph build resumes from its last finished stage instead of starting over (#1441, thanks @OlegAndreych).
- `bash_status`, `bash_watch` and `bash_kill` accept the build-server job ID of your own remote command.
- When `callers` finds no resolved callers, it lists same-name call sites as possible callers, marked unconfirmed.

## Changed

- On Linux, AFT returns freed memory to the system sooner, lowering its memory use during large index builds and at idle.
- AFT uses less idle CPU cleaning up finished shell commands.
- CortexKit: AFT uses the fleet message bus for late results, secret approval answers and runner delivery updates, keeping its existing checks as fallbacks.
- CortexKit apps: the shells list stops polling when nobody is watching.

## Fixed

- First index builds of large projects use a fraction of the memory and finish faster. In our tests on Linux, Chromium went from 30.9 GiB to 5.1 GiB (1,486 s to 865 s), VS Code from 17.9 GiB to 2.2 GiB, and Elasticsearch now builds in 3.0 GiB instead of running out of memory. Windows and macOS show similar drops; macOS peaks are higher than Linux because AFT uses the system allocator there (#1441, thanks @OlegAndreych).
- Search and grep name files they skip because a file or a single line exceeds 16 MiB, instead of reading them whole (#1432, thanks @tobwen).
- Foreground shell calls return as soon as a local command exits instead of waiting for the next check (#1459, thanks @gaojunran).
- Shell permission refusals name the command part that was denied (#1455, thanks @iceteaSA).
- Rust diagnostics no longer stay provisional when an include macro has parameters unrelated to the path (#1425, #1453, thanks @elmagow).
- Rust call graphs find callers through `Arc`, `Rc` and `Box` fields, and Rust outlines list trait methods, which zoom finds by name or `Trait::method`.
- `impact` on a heavily used symbol returns a marked-incomplete answer within seconds instead of timing out.
- Deeply nested source files no longer crash analysis; Markdown nested beyond what its parser handles safely is reported as unsupported.
- Inspection and language-server reads no longer hang on named pipes and other special files.
- Unusually complex C and Objective-C headers no longer hold up other analysis.
- rust-analyzer uses its own Cargo build folder, so it no longer blocks your builds on Cargo's lock.
- Rust diagnostics name a missing rustup component, an untrusted mise config or a busy analyzer instead of reporting a crash.
- Shortened `cargo test` output keeps every failing test's name and panic message.
- Markdown writes and edits give a targeted hint about table pipes instead of a misleading syntax verdict.
- Build-server commands: an explicit timeout also limits the queue wait, status shows time spent queued, and results survive expired file returns and AFT restarts.
- CortexKit: background command completions survive runner delivery failures and no longer leave stale reminders; head agents get background shells back immediately.
- CortexKit: the bot can resolve review threads on its own pull requests again, worker `gh run list --workflow` accepts workflow names, and the apps load AFT's tool views again.
- CortexKit: secret approval cards file reliably, and every refused secret request is logged with its reason.

## Security

- A GitHub write from an agent shell is checked against the connection that launched that shell, and refused if they don't match.
